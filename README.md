# Аудиополка

Android-приложение: каталог аудиокниг во встроенном браузере + скачивание книги на телефон + офлайн-плеер.

## Как пользоваться

1. Вкладка **Каталог** — открывается сайт. Найдите книгу и зайдите на её страницу (где плеер).
2. Нажмите **⬇ Скачать книгу** — приложение найдёт список глав и скачает их. Экран можно гасить.
3. Вкладка **Моя полка** → **Слушать**. Интернет больше не нужен.

Плеер: перемотка −15/+30 секунд, главы, скорость, таймер сна, управление с экрана блокировки и гарнитуры.
Место остановки запоминается для каждой книги отдельно.

Кнопка ⚙ в каталоге — сменить адрес сайта, если он переехал.

## Сборка (как у виджетов)

1. Создать репозиторий на GitHub, загрузить все файлы из архива в корень.
2. Создать файл `.github/workflows/build_apk.yml` и вставить в него содержимое `build_apk.yml`.
3. Actions → **Build APK** → Run workflow.
4. Забрать `audiopolka.apk` из Releases и установить.

## Файлы

| Файл | Назначение |
|------|------------|
| `MainActivity.kt` | Экран: полка, каталог (WebView), панель плеера |
| `DownloadService.kt` | Скачивание глав в фоне, докачка после обрыва |
| `PlayerService.kt` | Плеер, уведомление, экран блокировки, гарнитура, таймер сна |
| `Store.kt` | Хранение книг и позиции прослушивания |
| `extract.js` | Поиск списка глав на открытой странице |
| `ic_launcher.xml` | Иконка |
| `AndroidManifest.xml` | Разрешения и компоненты |
| `root_build_gradle.txt`, `app_build_gradle.txt`, `settings_gradle.txt`, `gradle.properties` | Gradle (AGP 8.7.3, Kotlin 2.0.21, Gradle 8.11.1) |
| `debug.keystore` | Постоянный ключ подписи — обновления ставятся поверх, книги не теряются |
| `setup_project.sh` | Разворачивает плоский репозиторий в структуру Android-проекта |
| `build_apk.yml` | GitHub Actions: сборка одним шагом, APK в Releases |

## Важно

- Книги лежат в папке приложения. При **удалении** приложения они удаляются; при обновлении поверх — остаются.
- Если сайт изменит устройство страницы и кнопка «Скачать книгу» перестанет находить главы — править нужно только `extract.js`.
- Внешних библиотек нет, только стандартный Android — меньше поводов для поломки сборки.
